LingoBridge privacy notice

Online translation

Online mode sends only the text you deliberately translate, its language choice, and the minimum request metadata needed for security to the LingoBridge gateway.

Who processes the text?

In Phase 4, the gateway sends the chosen text to NVIDIA Riva Translate 4B Instruct v2 first for supported directions. Google Cloud Translation Advanced is used only as a backup when it is configured and the requested direction is supported.

What LingoBridge keeps

The gateway does not create translation history and its operational logs do not contain source or translated text. A random installation identifier is stored only in the extension and used for abuse limits.

Your control

Online translation stays disabled until you allow it in the popup. You can turn it off there at any time. Disabling it prevents new text from being sent; it does not delete text you deliberately save in later product phases.

Read NVIDIA's model card and Google's Cloud Translation data usage terms.

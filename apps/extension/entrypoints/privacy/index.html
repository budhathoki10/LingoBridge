LingoBridge privacy notice

Online translation

Online mode sends only the text you deliberately translate, its language choice, and the minimum request metadata needed for security to the LingoBridge gateway.

Who processes the text?

The gateway sends the chosen text and language pair to MyMemory first. Every MyMemory request also includes the gateway owner's configured contact email in the provider's de parameter. If MyMemory fails or reaches its quota, NVIDIA Riva Translate 4B Instruct v2 is attempted once only for a supported language direction.

Explain

When you click Explain on a translation, the gateway sends only that selected text, its translation, and the two language codes to NVIDIA Nemotron 3 Ultra to write a short, simple explanation with examples in the language you translated into. Explain asks for its own permission the first time, works only on short phrases, and is never used unless you click it.

What LingoBridge keeps

The gateway does not create translation history and its operational logs do not contain source, translated, or explained text. Explanations are not saved. A random installation identifier is stored only in the extension and used for abuse limits.

Your control

Online translation stays disabled until you allow it in the popup. You can turn it off there at any time. Selecting webpage text only displays the magic icon; detection and translation start after you click it. Disabling Online translation prevents new text from being sent; it does not delete text you deliberately save in later product phases.

Read MyMemory's API specification, its terms, and NVIDIA's model card . Explanations use NVIDIA's Nemotron 3 Ultra model.

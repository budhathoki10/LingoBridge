Privacy notice

Online translation

Online mode sends only the text you deliberately translate, its language choice, and the minimum request metadata needed for security to the LingoBridge gateway.

Who processes the text?

The gateway sends the chosen text and language pair to MyMemory first. Every MyMemory request also includes the gateway owner's configured contact email in the provider's de parameter. If MyMemory fails or reaches its quota, NVIDIA Riva Translate 4B Instruct v2 is attempted once only for a supported language direction.

When the selected text looks like Nepali typed in English letters, the gateway first sends it to NVIDIA Nemotron 3 Ultra, or once to OpenRouter if NVIDIA fails, only to rewrite it in Nepali script. The rewritten text is then translated as above. If both fail, the extension converts common words on your device instead.

Explain

When you click Explain on a translation, the gateway sends only that selected text, its translation, and the two language codes to NVIDIA Nemotron 3 Ultra to write a short, simple explanation with examples in the language you translated into. Clicking a word sends that word, the selected text, and its translation the same way. Explain asks for its own permission the first time, works only on short phrases, and is never used unless you click it.

If NVIDIA fails or is too slow, the gateway sends the same request once to a model on OpenRouter. Free OpenRouter models are run by other companies whose terms may allow them to log or learn from requests, so do not explain text you would not share.

What LingoBridge keeps

The gateway does not create translation history and its operational logs do not contain source, translated, or explained text. Explanations are not saved. A random installation identifier is stored only in the extension and used for abuse limits.

Your control

Online translation stays disabled until you allow it while connecting this Chrome installation or through the separate first-translation consent. Selecting webpage text only displays the magic icon; clicking it opens the translator, and the text is sent only when you click Translate. Disabling Online translation prevents new text from being sent; it does not delete text you deliberately save.

Read MyMemory's API specification, its terms, and NVIDIA's model card . Explanations use NVIDIA's Nemotron 3 Ultra model, with OpenRouter as the backup. Read OpenRouter's privacy policy.

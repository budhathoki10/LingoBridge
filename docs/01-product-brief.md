# Product brief

## Product

- **Name:** LingoBridge
- **Tagline:** Understand the words in front of you.
- **Category:** Chrome translation extension with companion web dashboard
- **Language scope:** Every language currently supported by Google Cloud Translation, with deeper English–Nepali evaluation

## Problem

People often copy unfamiliar text, open another translation website, paste it, translate it, and return to the original page. This affects students, travellers, multilingual families, international workers, and ordinary users reading notices, articles, messages, documentation, and application instructions.

Literal translation also loses tone and context. Romanized Nepali is common in informal writing but is not handled consistently by traditional word-for-word tools.

## Intended users

- Nepali students reading English educational material.
- People messaging across English and Nepali.
- Travellers and migrants reading unfamiliar languages.
- Multilingual teams reading short messages and instructions.
- Job seekers reading vacancies and application instructions.
- Users who type Nepali using the Roman alphabet.
- Anyone who wants a quick translation without leaving the current page.

## Core promise

The user can select text, click the small magic icon shown beside it, and immediately see an anchored translator that detects the source language, translates into the user's preferred target language, and lets the user copy or use the result without leaving the page. When signed in, the user can deliberately save useful phrases and manage them from a web dashboard.

The language picker reflects the provider's current supported-language catalogue instead of shipping an artificial small list.

## Product principles

- User action always starts a translation.
- A stable text selection reveals the translation action; clicking its magic icon is the deliberate action that starts translation.
- The result appears close to the selected text.
- The original text remains visible.
- LingoBridge states whether translation happened on the device or online.
- Online processing sends only the text the user chose.
- AI uncertainty is visible instead of hidden.
- The user reviews a translation before it can replace text.
- Signing in is optional for translation but required for dashboard synchronization.
- The dashboard never becomes an automatic archive of everything translated.

## What makes it impressive

LingoBridge is more than a dictionary lookup. It combines instant multilingual translation with a deliberate personal phrase library that follows a signed-in user across the extension and dashboard. It preserves names and numbers, uses surrounding context only with permission, and explains ambiguous phrases without silently creating translation history.

## Product success

A first-time user should translate a selected sentence within fifteen seconds of enabling site access. A returning user should complete the action by selecting text and clicking the nearby magic icon; LingoBridge then detects the source and translates into the saved preferred target language.
